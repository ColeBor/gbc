## Week 1 - History
- Cuneiform is the oldest discovered writing system
- Printing is almost as old as writing

## Week 2 - Bits and Bytes
- Modern definition of a byte is a group of 8 bits
- Computers see the memory as one long sequence of bytes

## Week 3 - Markup Languages
- Markup before computers was used to proofread and edit papers
- Use a blackslash to "escape" a special character

## Week 4 - Keyabords & Editors
- Keyboard layouts are usually named after the top left row
- Word processors are different than text editors

## Week 5 - CLI
- Command line is great for working remotely
- When you type passwords, nothing is shown
